Design Pattern: Composite (Composite)

Structural design pattern

What is it?

Composite (Composite) — is a structural design pattern that allows you to compose objects into tree-like structures and then work with these structures as if they were individual objects.

Pattern Structure

  • Component: Defines a common interface for both simple leaf objects and complex composite objects in the tree.
  • Leaf: A simple tree element that has no child objects. It is the one that performs the main work.
  • Composite: A complex element that contains child elements (leaves or other composites). It delegates work to its child elements.

When to use?

This pattern is ideal when you need to implement a tree-like structure of objects. A classic example is a file system, where folders contain files and other folders. Thanks to the pattern, the program can handle both an individual file and a folder with hundreds of files in the same way.
